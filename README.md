# 📝 React Todo App

A simple and interactive Todo List built with React. Users can add tasks, mark them as complete, and delete them

## 🖥 Getting Started

#### 1. Clone the repo

```bash
git clone https://github.com/On-KeiShe/react-todo-app.git
```

#### 2. Navigate into the project folder

```bash
cd react-todo-app
```

#### 3. Install dependencies
```bash
npm install
```

#### 4. Start the development server
```bash
npm run dev
```
